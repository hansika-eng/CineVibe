# CineVibe 🎬

CineVibe is a cinematic Telugu movie recommendation web application inspired by modern OTT platforms like Netflix, Prime Video, and Aha.

It provides personalized movie suggestions based on genres, trending picks, and time-aware recommendations with a premium dark UI experience.

---

## ✨ Features

* 🎥 Cinematic OTT-inspired UI
* 🌙 Dark premium theme
* ⏰ Time-aware recommendations
* ❤️ Favorite/Watchlist system
* 🔍 Smart movie & cast search
* 🎭 Genre-based filtering
* 📈 Trending Telugu blockbusters section
* 📱 Responsive design
* 🎬 Movie detail modal
* ⭐ CineVibe score system
* 💾 LocalStorage support

## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/cinevibe.git
```

Move into the project folder:

```bash
cd cinevibe
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm start
```

Open:

```txt
http://localhost:3000
```
